# Игры: каталог и правила

## Задача
Участник или ведущий выбирает игру по аудитории, быстро раскрывает правила, смотрит расстановку и запускает сопровождение, не переходя между страницами. В отличие от песенника, музыка относится к конкретной игре: после окончания нет автоматического запуска следующей игры.

## Реализация
- /games/ — независимые фильтры категории и аудитории плюс поиск по названию, аудитории, правилам и реквизиту. Исторические/развлекательные группы сохранены, все исходные игры доступны, active остаётся метаданными.
- Отдельные аккордеоны с общей поверхностью заголовка и контента, единый набор SVG-пиктограмм, насыщенный красный акцент, обе темы.
- games.json не меняется. game-details.json содержит дополнительно извлечённые из описаний сведения: age_min/max, players_min/max, equipment, formation, role. Неизвестное не заполняется. Markdown отображается через markdown-it с отключённым raw HTML; первый дублирующий заголовок скрыт, остальные правила и речёвки сохранены.
- GameFormation.astro рисует универсальные условные схемы. Точки не указывают точное число игроков; движения и роли не выдумываются. GameIcon.astro обеспечивает единый стиль.
- Один hidden audio на каталоге, только архивные локальные MP3, Play/Pause, круговой прогресс и независимая перемотка. Глобальная координация audio остаётся в app.js; уход со страницы останавливает звук. Нет автоматического перехода к другой игре.
- Видео использует существующий external-embeds runtime: только по нажатию, без внешних iframe офлайн. Старые /games/slug/ оставлены для Pagefind и прямых ссылок; отдельная ссылка доступна внутри карточки, hash также раскрывает игру.
- Отдельный пошаговый режим ведущего и разделение всех длинных описаний на steps/lyrics — следующий этап, не подменять исходные правила автоматически.

## Защита
npm test проверяет метаданные и наличие архивных MP3; browser smoke проверяет комбинирование фильтров, раскрытие, схему, действительное воспроизведение и ленивое видео. Проверять 320/390/768/1440 px, обе темы, клавиатуру, cold offline и SPA. Не менять контракт песенника ради каталога игр.
