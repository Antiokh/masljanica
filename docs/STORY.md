# Сказ: живая книга

## Зачем
Посетитель читает сказ, а участник представления сверяется с репликами, ремарками и музыкальными вставками. Разделение на части условное; отдельные плитки и переходы между ними заменены аккордеонами на одной странице.

## Контракт
- /scenario/ — отдельный верхний тёплый блок «Что такое Масляница?» с декоративным солнцем, затем сценарий. Исторический текст хранится отдельно в src/data/maslyanica-history.md; текст восстановлен со скриншотов старого приложения. Отдельный аккордеон «Почему Масляница через „я“?» использует src/data/maslyanica-name.md, с подтверждёнными ссылками на Ушакова, Даля и Дубровского. Исторический текст отредактирован в двух местах: связь с равноденствием — версия, Сырная неделя предшествует Великому посту, а не приходится за месяц до Пасхи. Не выдумывать утраченные URL.
- Части I, II и завершение — native details, первая открыта по умолчанию; остальные можно раскрывать независимо. Сохранить 49 исходных реплик, их порядок, роли, переносы строк и ссылки на песни. Исходный scenario.json не переписывать.
- Портреты — существующий локальный character-archive, буквенный fallback; диалоги персонажей используют общий CharacterDialog и существующий делегированный controller (включая Telegram Back). Никаких внешних картинок.
- Цвета ролей различаются, читаемы в обеих темах. Явные постановочные ремарки (3,26,38,45,49) — отдельные блоки; скобочные указания в 4,19,21 — курсив. Ответы на загадки не превращать в постановочные ремарки.
- Три музыкальные вставки (2,30,33) используют архивные MP3; все варианты доступны, один hidden audio, круговой прогресс, горизонтальная перемотка. Выбор записи запускает её, окончание не запускает следующую. Закрытие части не прерывает аудио, уход со страницы останавливает. Ссылка на песенник дополнительная, не обязательная для проигрывания.
- /scenario/#part-N и #replica-N открывают нужную часть; старые detail routes сохранены для совместимости. Нет новых вложенных страниц.
- Режим «Моя роль» не реализован, возможен как отдельная задача.

## Проверки
npm test валидирует порядок, ссылки и локальное аудио; production smoke проверяет аккордеоны, диалоги, смену музыкальных вариантов, реальное воспроизведение и переходы SPA. Проверять 320/390/768/1440, обе темы, cold offline, Telegram Back. Не ослаблять тесты для прохождения сборки.
