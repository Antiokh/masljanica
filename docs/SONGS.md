# Песенник: интерфейс и воспроизведение

`/songs/` — основной песенник, компактный список всех песен. `src/pages/songs.astro` формирует список и проверяет локальные записи; `public/song-list.mjs` — транспорт и очередь. Старые detail pages сохраняются для прямых ссылок/Pagefind. Сценарий ссылается на /songs/#slug, hash раскрывает нужный текст.

## Инварианты

- Все записи песен берутся из `src/data/audio-archive.json`, строго `/media/audio/*.mp3`. Файл должен реально существовать в public, иначе сборка падает. Не заменять отсутствующий файл внешним URL. Архив — источник duration и пути; исходные ID/slug сохранять.
- Один attached native audio (#song-player-audio, preload=none, hidden) вне details. Не создавать audio на каждую строку/вариант и не переносить транспорт внутрь accordion.
- Play/Pause слева, раскрытие текста справа, независимые действия. Нажатие Play не раскрывает текст. Закрытие details не останавливает запись.
- Варианты исполнения — компактные круги с номерами; выбранный вариант занимает свободную ширину и показывает время. Прогресс по окружности отражает фактический currentTime/duration. Смена варианта запускает запись, а не только меняет видимую иконку.
- Очередь — порядок каталога, внутри песни порядок вариантов. Поиск только скрывает строки; не меняет очередь. ended запускает следующий track при наличии. При уходе со страницы плеер останавливается. Не допускать одновременного воспроизведения.
- play() вызывается синхронно из пользовательского действия для mobile autoplay policy; UI синхронизируется с native media events, ошибки доступны через role=status. Не показывать playing до фактического состояния транспорта.
- Hash navigation и lifecycle Astro должны работать после SPA swap, listeners делегированы. Учитывать prefers-reduced-motion.
- Видео вручную создаётся только онлайн; при offline скрывается целиком и не влияет на MP3/lyrics. См. [PWA](PWA.md).

## Проверки

Production smoke проверяет каталог, фильтрацию, независимость Play/accordion, варианты/выбранную капсулу, реальные currentTime и readyState онлайн и офлайн, переход к следующей записи, Range и cold/hot video offline. Дополнительно проверять медленный старт MP3, seek/pause, окончание последнего трека, hash из сценария, уход со страницы и повторный вход, узкий экран, обе темы. Изменять тесты вместе с согласованным изменением контракта, не ослаблять проверки только до CSS-флага playing.
