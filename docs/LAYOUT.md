# Layout и дизайн-система

См. [PWA](PWA.md) для состояния и [песенник](SONGS.md) для специализированных контролов. Эталон компактного статуса: [RSLive layout](https://github.com/Antiokh/rslive.ru/blob/main/astro/docs/components/layout.md).

## Общая система

Утверждены зимний день (белый фон, холодные светлые поверхности, киноварь) и зимняя ночь (сине-графитовые поверхности, тёплые акценты). Основные цвета задаются CSS variables в `src/styles/app.css`, не локальными копиями палитры. Сохранять контраст и читаемость. Не возвращать золотую тему Glide или угольно-чёрный фон. Темы light/auto/dark совместимы со Starlight: ключ starlight-theme, data-theme содержит resolved light/dark. Desktop ThemeSwitch, mobile ThemeSelect; синхронизация при смене OS, storage и SPA.

## Шапка и навигация

`Header.astro` владеет компоновкой, `PwaStatus.astro` — логотипом и меню состояния. Header flex: бренд с min-width:0 и ellipsis, controls с фиксируемой шириной; иконки в одинаковых hit areas. На мобильных (до 60rem включительно) основное меню фиксировано снизу: repeat(4,minmax(0,1fr)), Избушка / Песни / Игры / Ещё. Summary «Ещё» занимает такую же ячейку, как ссылки. Одинаковая вертикальная геометрия, gap, размеры SVG и padding; активный раздел подсвечен. Учитывать safe area и отступ контента, не закрывать последнюю строку. На desktop меню в шапке. Не возвращать «Частушки» в меню.

## PWA status

Логотип использует `/icon.svg` (владелец предоставит окончательный SVG отдельно). Размер frame 2.75rem desktop / 2rem mobile, object-fit:contain. Не привязывать геометрию к внутренним пропорциям SVG. Точка состояния в левом нижнем углу логотипа (не отдельная колонка); видима в standalone. Цвет: green online, blue offline + ready, red offline + unavailable, neutral gray unknown/download/delete. Приоритет busy над обычным состоянием. Не использовать accent киноварь для синего ready.

Единственный native popover `#festival-pwa-menu`, оба триггера используют один panel. Desktop — hover, keyboard focus, click; на mobile — tap по логотипу или status/⋮ первым блоком «Ещё». Позиционировать относительно фактического anchor: ниже верхнего логотипа при наличии места, выше нижнего триггера при необходимости, clamp к viewport. Не фиксировать экранные координаты и не наращивать z-index вместо top layer. Сохранять focus, Escape, light dismiss, повторный click; hover → click фиксирует уже открытое меню, а не закрывает его. На SPA swap закрывать menu и не оставлять ссылки на старые DOM nodes.

Пять строк с единой сеткой:
1. Подключение — Онлайн / Офлайн · копия доступна / Офлайн · копии нет / проверка.
2. Запуск — Браузер / Приложение.
3. Офлайн-копия — Готова / Устарела / Не скачана / Проверяем / Загрузка или Обновление N% / Удаление; рядом маленькая корзина.
4. Автообновление — двухпозиционный switch, без отдельной страницы для его включения.
5. Хранилище — оценка navigator.storage.estimate().usage всего origin, не точный размер pack.

Лейблы слева, значения и compact controls справа. Выравнивание строк по вертикальной оси, стабильные hit areas, текст может переноситься без горизонтального overflow. Не добавлять громоздкие action buttons, служебные сведения о регистрации SW или отдельную строку stage. Ссылка «Подробнее» и компактное действие Скачать/Обновить в footer. Прогресс по файлам, подпись «Прогресс · материалы», indeterminate до известного total. Тонкая линия вдоль нижней границы шапки, mobile status в «Ещё». В idle progress скрыт. Корзина disabled при отсутствии pack/staging, во время подготовки или удаления. Auto off сохраняет копию.

Presentation runtime получает модель из app.js; ни поповер, ни мобильное меню, ни /offline/ не определяют состояние самостоятельно. Storage estimate запрашивать по открытию/существенному изменению, не на каждом переходе.

## QA

Smoke проверяет desktop/mobile смену темы, hover/click/Escape, horizontal bounds меню при 390 px. Для layout-изменений обязательны реальные скриншоты/осмотр при 320, 390, 768 и 1440 px, обе темы, browser и standalone, длинные значения, loading/ready/stale/error и нижнее меню. Проверять одинаковые размеры четырёх hit areas, выравнивание корзины/switch и отсутствие скачков строк, clipping, наложений на theme/search и перекрытия контента. Проверить клавиатурный Tab/Shift+Tab, Escape и touch. Наличие smoke не подтверждает визуальную QA.
