# Масляница · Белград

**Приложение:** [masljanica.pages.dev](https://masljanica.pages.dev/)

Публичное приложение фестиваля: Astro 5 + Starlight, статическая генерация, русский интерфейс, светлая/тёмная тема, мобильная навигация, Pagefind и PWA.

```sh
npm install
npm test
npm run dev
npm run build
npm run preview
```

Node.js 22.12+. Cloudflare Pages: команда `npm run build`, каталог `dist`, без серверного адаптера. Приложение рассчитано на корень домена.

## Контент

`src/data/` — нормализованные публичные данные из Glide. `scripts/generate-content.mjs` генерирует Markdown-страницы из данных до запуска Astro. Slug — человекочитаемый идентификатор; исходные ID сохраняют связи сценария. CRM, идентификаторы исполнителей, отзывы и бронирования исключены.

Аудио архивируется в `public/media/audio/` через GitHub Actions **Archive audio** (`scripts/archive-audio.py`). Отчёт `src/data/audio-archive.json` хранит оригинальные URL, локальные пути, размер, SHA-256, длительность и ошибки. Генератор страниц использует локальные копии при наличии, иначе исходные URL. Офлайн-кэш включает архивированные MP3 и поддерживает Range-запросы для перемотки. YouTube и внешние иллюстрации остаются онлайн. Публикация записей в открытом репозитории предполагает наличие прав на их распространение. Изображений мастер-классов в CSV не было. Главная страница пока сокращена: социальные ссылки и исторический текст требуют отдельного восстановления.

Флаги active сохранены как метаданные, все песни и игры доступны в каталоге; неподтверждённые мастер-классы помечены «Уточняется».

Сборка генерирует версионированный Service Worker из фактических файлов dist. Офлайн проверяется в production preview, не в dev.

## Дизайн

Утверждённая палитра «Зимний день / Зимняя ночь» задана в `src/styles/app.css`: белый и ледяные поверхности днём, сине-графитовые ночью, киноварь и золотистые акценты. Мобильная навигация — четыре равные CSS Grid-колонки (Избушка, Песни, Игры, Ещё), с учётом safe area. Существующие маршруты и материалы сохранены.

## Быстрая навигация и офлайн

Принципы RSLive адаптированы для небольшого статического приложения: Astro ClientRouter + prefetch по намерению, один browser runtime с `astro:page-load`, лёгкий Service Worker и отдельная полная офлайн-копия по явной команде. После первой загрузки страницы текущей версии читаются из runtime-кэша; проверенная полная копия текущей версии обслуживается без сетевого запроса. Обновление полной копии копирует неизменившиеся ревизии и проверяет SHA-256 новых файлов перед атомарной сменой активного указателя. Старый архив сохраняется при ошибке. Установка PWA и загрузка полной копии разделены. Из RSLive перенесён чистый daily resolver: отдельное подтверждение локального хранилища, не более одного предложения установки/скачивания/обновления за локальный календарный день, автоматическая поддержка офлайн-копии по явному переключателю. Отключение автоматических обновлений не удаляет копию; удаление также отключает автообновление.

После изменения runtime проверять production build, переходы туда/обратно, поиск и фильтры, тему, холодный офлайн-старт, Range-аудио и обновление/удаление копии.
